# SMART
Repository di coordinamento del progetto SMART

## Repository collegate
- [DSS](https://github.com/protodesign-ufficio/SMART-DSS) --> Include la logica di gestione del db e i servizi di ottimizzazione
- [KAFKA-TELEGRAF](https://github.com/protodesign-ufficio/SMART-KAFKA-TELEGRAF) --> Include le configurazioni di Kafka e Telegraf per l' ingestione dei dati
- [KAFKA-SERVICES](https://github.com/protodesign-ufficio/SMART-KAFKA-SERVICES) --> Include i servizi consumer dei topic Kafka
- [LIVING-MAP](https://github.com/protodesign-ufficio/SMART-LIVINGMAP) --> Include l' intero frontend, livingmap e dashboard analytics

La documentazione degli specifici moduli è presente nella cartella docs/ del repository associato
